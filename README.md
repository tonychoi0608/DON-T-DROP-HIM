# 부장님이 잠드셨다 (DON'T DROP HIM)

> **떨어뜨리지 말고, 깨우지 말고, 집까지.**
> 회식에서 잠들어버린 부장님을 두 명이 앞뒤로 들고 집까지 배달하는 물리 협동 게임 — PC·모바일 30개 고유 맵 캠페인 v0.7.0

한 문장 규칙: **"잠든 부장님을 깨우지 않고 집까지 옮겨라."** (3초 안에 이해되는 그림 — 바이럴 게임 27종 분석에서 나온 유일한 만장일치 조건)

## 실행

빌드 없음. 파일 하나가 게임 전부입니다.

```bash
open index.html
```

또는 아무 정적 서버로 서빙:

```bash
python3 -m http.server 8791
```

PC는 키보드, 스마트폰·태블릿은 화면 양쪽의 조그다이얼 스틱으로 플레이합니다. 모바일은 가로 화면을 권장하며 최신 크롬/엣지/사파리를 지원합니다.
실제 마이크 기능을 사용할 때는 브라우저 보안 정책상 `file://` 직접 열기보다 위 정적 서버 방식 또는 HTTPS 배포본을 사용하세요.

## 조작

| 역할 | 이동 | 점프 | 숙이기 | 그립 잡기/놓기 |
|---|---|---|---|---|
| 🟦 뒷사람 (부장님 다리) | A / D | W | S | F |
| 🟩 앞사람 (부장님 팔) | ← / → | ↑ | ↓ | Shift 양쪽 (또는 L) |

- **[1] 혼자 연습** — 한 사람이 왼손(WASD)과 오른손(방향키)으로 두 캐릭터를 동시에 조작. QWOP 계열의 두뇌 분할 챌린지이자, 협동 모드 연습장.
- **[2] 둘이서 협동** — 키보드를 반씩 나눠 잡는 로컬 협동. 서로 탓할 준비 필수.
- R 체크포인트 재시작(숙면도 회복 없음) · P 일시정지 · M 음소거 · V 실제 마이크 ON/OFF
- 레벨 클리어 후 Enter 다음 레벨 · T 현재 레벨 재시작 · Esc 타이틀
- `?debug` URL 파라미터: K(숙면도 감소) · 9(전진 텔레포트) · 0(숙면도 회복) · I(사고 판정 테스트) · G(현관 이동)

### 모바일 터치

- 왼쪽 파란 스틱(뒷사람)·오른쪽 초록 스틱(앞사람): 손가락 하나로 좌우로 밀면 이동, 위로 튕기면 점프, 아래로 내리면 숙이기
- 스틱 옆 원형 버튼: 그립 잡기·놓기
- 상단 메뉴: 일시정지, 체크포인트 재정비, 음소거, 다음 단계, 다시하기, 타이틀
- 손가락을 독립 추적하므로 한 손가락은 스틱, 다른 손가락은 그립 버튼을 동시에 사용할 수 있습니다.

## 영어판 (English build)

[`en.html`](en.html)은 [`tools/build-en.py`](tools/build-en.py)의 번역 테이블로 `index.html`에서 자동 생성되는 영어 버전입니다. 타이틀 우측 상단 **🌐 English / 🌐 한국어** 버튼으로 서로 전환됩니다. 한국어 원본을 수정한 뒤에는 다음을 다시 실행하세요:

```bash
python tools/build-en.py
```

새 한국어 문자열은 스크립트의 `T` 테이블에 번역을 추가하면 되고, 누락분은 `tools/en-leftovers.txt`로 보고됩니다.

## 온라인 협동 (v0.7.0)

타이틀 우측 하단 **🌐 온라인 협동 [3]** 버튼으로 친구와 원격 2인 플레이가 가능합니다.

1. 방 이름을 적고 **방 만들기** — 방이 공개 로비 목록에 올라갑니다
2. 다른 사람은 로비의 **열린 방 목록**(3초마다 갱신)에서 원하는 방을 골라 **입장**
3. 각자 **앞사람 / 뒷사람** 역할 선택 (중복 불가)
4. 방장(👑)이 **게임 시작** — 시작된 방과 인원이 찬 방은 목록에서 사라집니다

동기화는 호스트 권위 방식입니다: 방장 브라우저가 물리 시뮬레이션을 담당하고, 상대는 입력을 보내고 15Hz 상태 스냅샷을 받아 렌더링합니다. 맵은 레벨별 고정 시드라 양쪽이 동일한 지형을 봅니다.

### 중계 서버 배포 (Cloudflare Workers, 무료 플랜 가능)

게임 본체는 Cloudflare Pages(정적)에 그대로 두고, 방 관리·WebSocket 중계만 [`worker/`](worker/)의 Worker + Durable Object가 담당합니다.

```bash
cd worker
npx wrangler deploy
```

배포가 끝나면 출력되는 `https://dont-drop-him-online.<계정명>.workers.dev` 주소를 게임의 온라인 로비 "중계 서버 주소" 칸에 한 번 입력하면 됩니다(`wss://…`로 자동 변환, localStorage에 저장). 로컬 테스트는 `npx wrangler dev`로 `ws://localhost:8787`을 사용하세요.

## 30레벨 캠페인

v0.6.2부터 30개 레벨은 각각 **고유 레시피**(지형 어휘 + 배치 곡선 + 이벤트 위치 + 테마)로 생성됩니다.

| 요소 | 레벨 1 | 레벨 30 | 설명 |
|---|---:|---:|---|
| 길이 | 420m | 900m | 레벨마다 다르게 증가 |
| 장애물 | 24개 | 100개 | 남은 공간 기준 자동 밀도(간격 160px→96px) — 1레벨부터 포화 배치 |
| 장애물 종류 | 14종 | 14종 | 레벨마다 2~5종의 고유 조합(계단·천장·터널·피라미드·좌판·징검다리 등) |
| 배치 곡선 | — | — | even/front/back/mid/waves/breath/finale/rhythm 8종 중 레벨별 지정 |
| 천장 통과 여유 | 60px | 44px | 부장님 머리 지름 30px — 처음부터 끌면서 기어가야 하는 구간 존재 |

고양이·쓰레기봉투·택시·정숙 구간·체크포인트 위치도 레벨마다 전부 다른 비율로 배치되며, 배경 테마 6종(회식 골목·새벽 시장·공사장·지하도·강남대로·아파트 언덕)이 레벨 이름에 맞춰 개별 지정됩니다. 같은 레벨을 다시 시작하면 동일한 지형이 나오지만, 30개 맵끼리는 지형 시그니처가 전부 다릅니다. 스탯 커브도 v0.6.2에서 전면 상향: 1레벨이 기존 9레벨 수준(피해 1.95배, 그립 73, 시작 숙면도 82, 체크포인트 2개)에서 시작해 30레벨은 피해 4.4배·그립 38·시작 숙면도 50·제한 90초까지 조여듭니다. 튜토리얼 없이 처음부터 "이걸 왜 못 하지" 난이도입니다.

## 규칙

- **숙면도 게이지**가 0이 되면 부장님이 깨어난다 → 낙하 사고 **과실 비율 판정** 화면(뒷사람 n% : 앞사람 m%, 주요 혐의 포함. 무과실은 없다).
- 큰 충돌은 0.4초 슬로모션과 함께 최근 1.5초의 이동 속도·당김·그립·거리·충돌 부위를 분석해 즉시 과실을 판정한다.
- 한 명이 놓친 부장님을 다른 한 명이 버티거나, 추락 직전 다시 잡으면 **팀워크 구조·독박 운반·기사회생·간발의 차** 클립 점수를 얻는다.
- 낙하 충격·바닥 끌기·소주병·고양이·과속이 숙면도를 깎는다. 간판 아래에선 숙여야 하는데, 숙이면 부장님이 끌린다. 턱에선 둘이 박자 맞춰 점프해야 한다.
- 숙면도는 숙면→얕은 잠→반수면→기상 직전으로 변하며, 반수면에서는 갑자기 눈을 뜬다. 이때 2~3초간 움직이면 추가 피해를 받는다.
- **Silent Event는 마이크 없이도 발동**하며, 화면 좌우에 앞사람·뒷사람에게 서로 다른 위험 정보를 보여준다. 실제 마이크는 기본 OFF인 선택 기능이고, 켜면 큰 소리와 Silent Event 중 대화 소음이 숙면도를 추가로 깎는다.
- 굴러간 소주병이 쓰레기봉투와 고양이를 연쇄적으로 건드릴 수 있다. 중간의 택시에 부장님을 조심히 내려놓으면 800m를 단축하지만, 택시는 시작 15초 안에 도착하지 못하면 떠나버린다. 출발 직후 한눈팔지 않고 직행해야만 잡을 수 있고, 후반 레벨은 택시가 더 멀어서 사실상 전력 질주 전용이다.
- 매 판 무작위 **오늘의 미션**이 주어지며, 현관 도착 후 **회식 귀가 보고서**에서 사고왕·구조왕·기록·미션 성공 여부를 정산한다.

| 음주 미화 리스크 회피 | 주인공은 '고생하는 부하직원', 부장님은 희화화 대상 |

## 기술

- 의존성 0 — 순수 HTML5 Canvas + 커스텀 Verlet 물리(랙돌 12점 + 제약 19개) + WebAudio 신스 사운드(외부 에셋 없음)
- 마이크 기능은 브라우저 `getUserMedia`의 RMS 음량만 사용하며 음성 내용은 저장·전송하지 않음
- 단일 HTML 파일. 게임학과 팀이 Unity/Godot로 재구현할 때 물리·맵 생성·사고 판정 파라미터 레퍼런스로 사용 가능
