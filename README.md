# 부장님이 잠드셨다 (DON'T DROP HIM)

> **떨어뜨리지 말고, 깨우지 말고, 집까지.**
> 회식에서 잠들어버린 부장님을 두 명이 앞뒤로 들고 집까지 배달하는 물리 협동 게임 — 프로토타입 v0.1

한 문장 규칙: **"잠든 부장님을 깨우지 않고 집까지 옮겨라."** (3초 안에 이해되는 그림 — 바이럴 게임 27종 분석에서 나온 유일한 만장일치 조건)

## 실행

빌드 없음. 파일 하나가 게임 전부입니다.

```bash
open index.html
```

또는 아무 정적 서버로 서빙:

```bash
python3 -m http.server 8791
```

키보드 전용(데스크톱 브라우저). 크롬/엣지/사파리 최신 버전 권장.

## 조작

| 역할 | 이동 | 점프 | 숙이기 | 그립 잡기/놓기 |
|---|---|---|---|---|
| 🟦 뒷사람 (부장님 다리) | A / D | W | S | F |
| 🟩 앞사람 (부장님 팔) | ← / → | ↑ | ↓ | 오른쪽 Shift (또는 L) |

- **[1] 혼자 연습** — 한 사람이 왼손(WASD)과 오른손(방향키)으로 두 캐릭터를 동시에 조작. QWOP 계열의 두뇌 분할 챌린지이자, 협동 모드 연습장.
- **[2] 둘이서 협동** — 키보드를 반씩 나눠 잡는 로컬 협동. 서로 탓할 준비 필수.
- R 체크포인트 재시작 · P 일시정지 · M 음소거 · `?debug` URL 파라미터: K(숙면도 감소) 9(전진 텔레포트) 0(숙면도 회복)

## 규칙

- **숙면도 게이지**가 0이 되면 부장님이 깨어난다 → 낙하 사고 **과실 비율 판정** 화면(뒷사람 n% : 앞사람 m%, 주요 혐의 포함. 무과실은 없다).
- 낙하 충격·바닥 끌기·소주병·고양이·과속이 숙면도를 깎는다. 간판 아래에선 숙여야 하는데, 숙이면 부장님이 끌린다. 턱에선 둘이 박자 맞춰 점프해야 한다.
- 부장님은 주기적으로 **뒤척인다**(경고 1.2초 후 잠꼬대 또는 발작 — 절반은 무해, 절반은 위험).
- 현관에 조심히 내려놓으면 **인사고과 정산**: 시간·소음·기상 횟수·과실 누계로 S~F 등급.

## 왜 이 설계인가 (리서치 요약)

2023~2026년 스트리머발 바이럴 게임 27종 해부 + 감정 심리학 리서치에서 도출한 원칙을 그대로 구현했습니다. 상세는 `RESEARCH.md` 참고.

| 리서치 결론 | 게임에서의 구현 |
|---|---|
| 실패의 범인이 화면에서 특정되고 처벌은 전원 공유 (남탓 코미디 자동 생성) | 과실 비율 판정 화면, 앞/뒤 역할 분리, 공동 실패 |
| 실패 화면에 "얼마나 아까웠는지"를 박아라 (니어미스 효과, Clark 2009) | "집까지 겨우 206m 남기고…" 문구 |
| 실패는 아프지 않고 웃기게 (죄책감 없는 샤덴프로이데) | 랙돌 물리, 넥타이 머리띠, 잠꼬대, 과장된 연출 |
| 60~90초 긴장→해소 리듬, 해소 순간에 웃음 배치 | 장애물 구간 → 체크포인트 → 클리어 컷신("…또 회식이야?") |
| 물리로 실력 평준화 + 3초 룰 + 즉시 재시작 | 한 문장 규칙, R 리트라이, 짧은 코스 |
| 미션 도네이션이 걸릴 이산적 목표 | S~F 인사고과, 노기상 클리어, 타임어택 |
| 직장 하이퍼리얼리즘 공감 코드는 검증됐지만 게임 쪽은 공백 | 회식 → 부장님 배달이라는 소재 자체 |
| 음주 미화 리스크 회피 | 주인공은 '고생하는 부하직원', 부장님은 희화화 대상 |

## 기술

- 의존성 0 — 순수 HTML5 Canvas + 커스텀 Verlet 물리(랙돌 12점 + 제약 19개) + WebAudio 신스 사운드(외부 에셋 없음)
- 단일 파일 ~1,200줄. 게임학과 팀이 Unity/Godot로 재구현할 때 물리 파라미터 레퍼런스로 사용 가능
